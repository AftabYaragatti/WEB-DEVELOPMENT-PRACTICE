ANIMATIONS PROPERTY IN CSS

Animation Defines how the animation should run.

@keyframes defines the different stages of your animation.

BASIC ANIMATION

BOX-A101

OTHER PROPERTY WITH ANIMATION

BOX-A102

KEYFRAMES STAGES IN ANIMATIONS (0% 50% 100%)

BOX-A103

KEYFRAMES STAGES IN ANIMATIONS (0% 25% 50% 75% 100%)

BOX-A104

ANIMATION NAME

Syntax : .box{animation-name:name;}
@keyframes name{from... to...}
Tells CSS which @keyframes animation to use.

BOX-B101

ANIMATION DURATION

Controls how long one animation cycle takes.

BOX-B102

ANIMATION TIMING FUNCTION

Controls the speed pattern.

Common values : linear/ease/ease-in/ease-out/ease-in-out

BOX-B103

ANIMATION DELAY

Controls how long the browser waits before starting the animation.

Page loads->Wait 2 seconds->Animation starts

BOX-B104

ANIMATION ITERATION COUNT

Controls how many times the animation runs.

Common Values : 1s/2s etc or infinite

BOX-B105

ANIMATION DIRECTION

Controls which direction the animation plays.

Common Values : normal/reverse/alternate

BOX-B106

ANIMATION SHORTHAND PROPERTY

animation : [animation-name] [animation-duration] [animation-timing-function] [animation-delay] [animation-iteration-count] [animation-direction]

Example : animation: moveBox 2s ease 2s infinite alternate;

BOX-B107

ANIMATION FILL MODE PROPERTY

none : Default behavior. The element doesn't retain the animation's final styles.

forward : After the animation finishes, the element keeps the final keyframe.

backward : Applies the first keyframe during the delay period. This becomes more useful when you combine

Both : forward + backward

BOX-C101

ANIMATION PLAY STATE PROPERTY

Controls whether an animation is: running/paused(paused use with hover property)

BOX-C102

ANIMATION SHORTHAND PROPERTY

    .box {
    animation-name: moveBox;
    animation-duration: 2s;
    animation-timing-function: ease;
    animation-delay: 1s;
    animation-iteration-count: infinite;
    animation-direction: alternate;
    animation-fill-mode: forwards;
    }

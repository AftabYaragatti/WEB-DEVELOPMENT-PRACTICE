Transition Shorthand property

        Instead of writing:
        .box {
            transition-property: transform;
            transition-duration: 0.5s;
            transition-timing-function: ease;
            transition-delay: 0s;
        }
        we can write this :
        .box {
            transition: transform 0.5s ease 0s;
        }

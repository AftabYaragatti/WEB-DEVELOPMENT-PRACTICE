CLIP PATH PROPERTY

clip-path controls which part of an element is visible. Think: "Cut my element into this shape."

Clip-Path:Circle(50%) = Create a circular visible area.Only the circular portion is visible.

Clip-Path:Circle(50%) = 40% Smaller circle. / 60% Lager Circle

Clip-Path:Circle(circle size at horizontal position vertical position) = Move the circle. We can specify the circle's position.

Clip-Path:ellipse(horizontal radius vertical radius)

Clip-Path:ellipse(horizontal radius vertical radius at X-coordinate y-coordinate) = The code behaves exactly like clip-path: ellipse(50% 40% at 50% 50%)

Clip-Path:inset(20px) = 20px from top/20px from right/20px from bottom/20px from left

clip-path: inset(20px 30px 40px 50px) = top right bottom left

clip-path: inset(20px round 30px) = Rounded inset(), We can also create rounded corners

clip-path: polygon((top-right),(upper-right bottom),(bottom tip),(upper-left bottom)) = Example clip-path: polygon(0 0,100% 0,100% 80%,50% 100%,0 80%);

clip-path: polygon() = Triangle using polygon() = clip-path: polygon(50% 0,100% 100%,0 100%);

clip-path: polygon() = Diamond - clip-path: polygon(50% 0,100% 50%,50% 100%,0 50%);

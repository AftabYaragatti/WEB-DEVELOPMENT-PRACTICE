BASIC SELECTORS

1.Universal Selector(*) :

It will selects all the elements on the page & applies the same style on all universally.

2.Element Selector :

Targets all elements of a specific type, such as paragraphs or headers.

3.Class Selector(.) :

Applies styles to elements with a specific class attribute.

Another paragraph with class name only hello

4.ID Selector(#) :

Styles a single element identified by its unique id.

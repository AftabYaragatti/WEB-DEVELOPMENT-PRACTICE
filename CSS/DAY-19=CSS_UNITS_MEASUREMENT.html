UNITS MEASUREMENT

  1. Absolute Units (Fixed Sizes) : Absolute units are always the exact same size. They do not change when a user resizes their browser window.
    • px(pixels)
    • pt(points)
    • cm / mm / in (Centimeters / Millimeters / Inches)
  2. Relative Units (Flexible & Responsive) : Relative units change their size based on something else, like the font size of the text or the size of the computer screen. These units are the secret to making modern, mobile-friendly websites.
    • rem(Root EM)
    • em(Element EM)
    • ch(Character)
  3. Viewport-Relative Units : The "viewport" is simply the browser window area where the website is visible. These units change instantly when you resize the window.
    • vw (Viewport Width)
    • vh (Viewport Height)
    • vmin (Viewport Minimum)
    • vmax (Viewport Maximum)
  4. Percentages% (Percentage): Sized relative to its parent container box. If a parent box is 500px wide, an internal box set to 50% will display at 250px wide.

px (Pixels): The most common unit used for screens. One pixel represents a single tiny dot on your monitor.

pt (Points): A traditional unit used mostly for print styles and fonts.

cm / mm / in (Centimeters / Millimeters / Inches): Standard real-world physical measurements used almost exclusively for printing web pages onto physical paper.

rem (Root EM): Sized relative to the root () text size. If the browser's default font size is 16px, then 1rem equals 16px. If you change the root size, everything scales beautifully.

em (Element EM): Sized relative to the text size of its immediate parent element.

ch (Character): Equal to the width of the number "0" (zero) in the chosen font. It is perfect for limiting how many characters fit on a single line of text.

vw (Viewport Width): A percentage of the browser window's full width. 10vw means exactly 10% of the screen width.

vh (Viewport Height): A percentage of the browser window's full height. 100vh means the element will take up the entire height of the screen.

vmin (Viewport Minimum): Uses the smaller value between the screen's width or height.

vmax (Viewport Maximum): Uses the larger value between the screen's width or height.

% (Percentage): Sized relative to its parent container box. If a parent box is 500px wide, an internal box set to 50% will display at 250px wide.

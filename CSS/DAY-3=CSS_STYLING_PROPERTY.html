Color Formats in CSS

  1. Color Names : Example = Blue, Green etc
  2. Hexadecimal Codes : Example = 6-Digit Hex-codes (#FF5733)
  3. RGB (Red, Green, Blue) : Example = rgb(255, 0, 0)
  4. RGBA (Red, Green, Blue, Alpha) : Example = alpha (transparency) value (e.g., rgba(255, 0, 0, 0.5)).
  5. HSL (Hue, Saturation, Lightness) : Example = hsl(120, 100%, 50%)
  6. HSLA (Hue, Saturation, Lightness, Alpha) : Example = hsla(120, 100%, 50%, 0.5)

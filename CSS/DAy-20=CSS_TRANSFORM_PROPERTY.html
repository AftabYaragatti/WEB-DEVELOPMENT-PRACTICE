TRANSLATE PROPERTY



Translate() : transform: translate(X-axis, Y-axis)

translate() moves an element from its original position.(X-axis → left/right... Y-axis → up/down)



TranslateX() : Move only horizontally

Move only horizontally.+ -> Move Right, - -> Move Left.



TranslateY() : Move only vertically

Move only vertically.+ -> Move Down, - -> Move Up.



TranslateZ() : Move along with Z-axis

Move along with Z-axis



SCALE PROPERTY



scale() — Make an element bigger or smaller

2 means 200% of the original size.scale(1) → original/scale(2) → 2× bigger/scale(0.5) → half size



scaleX() — Resize Horizontally

scaleX()



scaleY() — Resize Vertically

scaleY()



scale(x,y) — Control both

scale(x,y)



ROTATE PROPERTY



Rotate() - Rotate an element

+ -> Clockwise Direction/ - -> Anticlockwise/counter-clockwise



RotateX() - Rotate an element in X-axis

+ -> Clockwise Direction/ - -> Anticlockwise/counter-clockwise



RotateY() - Rotate an element in Y-axis

+ -> Clockwise Direction/ - -> Anticlockwise/counter-clockwise



RotateZ() - Rotate an element in Z-axis

+ -> Clockwise Direction/ - -> Anticlockwise/counter-clockwise



SKEW PROPERTY



Skew() - Makes an element look slanted/tilted.

skew(x-axis,y-axis) values are in terms of degree.



SkewX() - Tilts horizontally.

skewX(x-axis) values are in terms of degree.



SkewY() - Tilts vertically.

skewY(y-axis) values are in terms of degree.



MATRIX(TRANSLATE, SCALE,ROTATE,SKEW) PROPERTY Each parameters have 2 values x & y axis values



Matrix() Combines several transform operations into a mathematical transformation matrix.

MATRIX(TRANSLATE, SCALE,ROTATE,SKEW) each having x & y axis values.



MULTIPLE TRANSFORM PROPERTY



We can apply multiple transformations together.

Order should be matter - Translate()-Rotate()-Scale()



TRANSFORM-ORIGIN PROPERTY



transform-origin:center

By default transformation happens around the center of the element



transform-origin:top left/top right

By default transformation happens around the center of the element



transform-origin:bottom left/bottom right

By default transformation happens around the center of the element



TRANSFORM-ORIGIN WITH PERCENTAGE PROPERTY



transform-origin:50% 50%

top-left : 0% 0%/center : 50% 50% / bottom-right : 100% 100% (x & y)



TRANSFORM-STYLE PROPERTY



transform-style:used for 3D transformation

preserve-3d/flat = values

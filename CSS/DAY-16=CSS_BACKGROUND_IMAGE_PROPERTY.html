BACKGROUND-SIZE

background-size:cover

Fill the entire box perfectly by scaling up and cropping the extra edges



background-size:contain

Scales down so the entire picture is visible, leaving gaps on the sides



background-size:100% 100%

Forces stretching to hit the exact margins

IMAGE COLOR CHANGING PROPERTY

background:linear-gradient() : The color changes in a straight line.

background-image(or we can use only background):linear-gradient(color1,color2),url()



background-image:linear-gradient(0deg,color1,color2),url()



background-image:linear-gradient(direction,color1,color2),url()

DIRECTIONS : to right / to left / to top / to bottom / to top right / to top left / to bottom right / to bottom left



background:radial-gradient() : This gradient spreads outward from a central point.

background:radial-gradient(circle(shapes),color1,color2) - The center starts with the first color and spreads outward. Other Values with shape :circle/ellipse followed by closest-side/farthest-side/closest-corner/farthest-corner



background:conic-gradient() : This gradient rotates around a center point, like a color wheel.

background:conic-gradient(color1,color2)



background:repeating-linear-gradient() : This is like linear-gradient(), but the pattern repeats.

background:repeating-linear-gradient(deg/direction(optional) color1,color2)



background:repeating-radial-gradient() : This is like radial-gradient(), but the pattern repeats.

background:repeating-radial-gradient(shape(optional) color1,color2)

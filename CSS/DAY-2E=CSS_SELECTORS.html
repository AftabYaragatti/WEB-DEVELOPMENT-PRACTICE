PSEUDO ELEMENTS

1. ::before :

To insert some content before an element.

Example :

WELCOME TO THE CODING WORLD

2. ::after :

To insert some content after an element.

Example :

WELCOME TO THE CODING WORLD

3. ::first-line :

Styles the first line of text within a block element. Line breaks mark the beginning of a new line.

Example :

Hello Welcome you all for
Coding world

4. ::first-letter :

It Styles the first-letter of a word or a sentence.

Example :

Hello Welcome you all for Coding world

5. ::placeholder :

Styles the placeholder of a specific input field.

Example :

Name :

Email :

Password :

ATTRIBUTE SELECTORS

1. Presence Selector:

It selects elements that contain a specific attribute.

Example :

Registration Form First Name :

Middle Name :

Last Name :

Password :

Email Id :

2. Attribute Value Selector:

It targets elements with a particular attribute value.

Example :

Registration Form Roll Number :

Password :

Email Id :

3. Substring Matching(^=):

It matches elements where the attribute contains a substring.

Example :

Secure link Non-secure link

4. Wildcard Selector (*=):

Matches elements where the attribute value contains a specific string.

Example :

This contains 'example' and is underlined. This is not underlined.

5. Ends With Selector ($=):

Matches elements whose attribute value ends with a specific string.

Example :

This link ends with '.pdf' and is red. This link ends with '.docx' and its as it is

6. Word Match Selector (~=):

Matches elements whose attribute contains a specific whole word (space-separated).

Example :

This paragraph has both 'highlight' and 'important' classes.

This paragraph has only the 'highlight' class.

7. Hyphen Match Selector (|=):

Matches elements whose attribute value starts with a word followed by a hyphen.

Example :

This paragraph is in English (US).

This paragraph is in English (GB).

This paragraph is in French.
